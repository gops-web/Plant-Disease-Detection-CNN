# Explainable Plant Disease Detection System Using CNN and Transfer Learning

## Project Overview

This project develops an automated plant disease detection system using Convolutional Neural Networks (CNNs) and Transfer Learning techniques. The objective is to classify plant diseases from leaf images and compare the performance of a custom CNN model with a MobileNetV2-based architecture.

## Dataset

**Dataset:** PlantVillage Dataset

**Dataset Link:** https://www.kaggle.com/datasets/emmarex/plantdisease

### Dataset Statistics

* Total Images: 20,639
* Number of Classes: 15
* Image Type: RGB Color Images

## Models Used

### Custom CNN

* Convolution Layers
* Max Pooling Layers
* Dropout Layer
* Dense Layers
* Softmax Output Layer

### Transfer Learning Model

* MobileNetV2

## Evaluation Metrics

The following metrics were used to evaluate model performance:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix
* Classification Report
